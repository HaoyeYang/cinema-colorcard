# Cinema Colorcard · 电影色卡

[在线浏览](https://haoyeyang.github.io/cinema-colorcard/) · [图像与证据来源](SOURCES.md)

从电影画面中整理颜色。第一章是**电影里的绿**：20 部影片、60 个取样区域，
从春意草地、盛夏树荫、秋日湖水到冬季常绿林，再延伸到都市、爱情、科幻与奇幻中的绿色。
之后可继续整理蓝、红、黄等颜色章节。

在原先 8 部影片的绿色图谱上，新增《1917》《月升王国》《龙猫》《远离天堂》
《卡罗尔》《天使爱美丽》《黑客帝国》《迷魂记》《堕落天使》《绿衣骑士》
《潜行者》《幽灵公主》。每部影片选一张具体画面，不把单帧配色当作整部影片的唯一风格。

## 浏览

- 按四季、跨季节主题和片名筛选；多个主题需同时满足。
- 点击画面查看完整原图，切换到原始像素尺寸；图片保持原始比例。
- 显示取样框，核对每个色块对应的区域；选 2–3 部影片并排比较。
- 展开来源信息，查看图像尺寸、版本说明、原图链接、ICC 处理、ROI 与文件校验值。

季节标签区分**剧情依据**和**画面观感**。《黑客帝国》等没有明确季节用途的例子
归入跨季节主题。颜色的情绪解读是本项目的阅读，不等同于已证实的创作意图。

## 清晰度与颜色

保存来源 JPG 的原始字节，没有再次压成网页缩略图；不调色、不裁切、不锐化、不做 AI 放大。
当前图片宽度为 844–1924 像素。吉卜力两张为官方 1920 像素场面写真；
《潜行者》采用 Janus Films 提供的 1480 × 1080 剧照。
部分旧来源只有约 1000 像素，《春夏秋冬又一春》为 844 × 460；保留真实尺寸和限制，
不把插值放大当作高清。

这让网页尽量忠实于所引用的图像，但**不等于校准过的电影母版颜色**。
多数图库未注明具体发行版本；不同版本、编码、屏幕和色彩管理仍可能产生差异。
原图文件中的 ICC 被保留，浏览器负责显示；仅测量时转换至 sRGB，未嵌入 ICC 的文件按 sRGB 假设处理。

每个色样取矩形区域内 R/G/B 各通道中位数，四舍五入到 8-bit 整数。
由该代表色计算 HSL 色相 H、CIELAB D65 明度 L*、彩度 C* 与 CIEDE2000 色差。
这个代表色不一定恰好等于区域内某一个像素。IQR 记录区域内部各通道的分散程度。

比较基准是 ColorChecker 24 色中的四种绿，数值来自
[BabelColor 的 20 张色卡平均 sRGB 数据](https://babelcolor.com/index_htm_files/RGB%20Coordinates%20of%20the%20Macbeth%20ColorChecker.pdf)。
“最近参考绿”只是在这四种颜色中距离最小，不保证相似；它们从未用于校正截图。
当 C* < 5 时标记色相不可靠。《荒野猎人》等例子中的常绿林实际偏青蓝，也如实保留。

## 本地运行与更新

纯静态页面，无运行时依赖、外部字体、分析追踪或 API。直接打开 `index.html` 即可，
也可在仓库目录启动：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

浏览 `http://127.0.0.1:8000/`。仅修改内容或重新取色时需要 Python 3.12+ 与依赖：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/build_atlas.py
.venv/bin/python scripts/build_atlas.py --check
node --check app.js
```

`--check` 会重新解码原图，核对 SHA-256、尺寸、ROI 边界与全部生成内容的一致性。
不联网、不下载或改写电影图片。当前数据用 Python 3.14 生成。

| 文件 | 用途 |
| --- | --- |
| `data/catalog.json` | 人工维护的影片、主题、季节依据、来源与像素取样框 |
| `data/references.json` | 参考色与来源 |
| `assets/frames/` | 未改写的来源图像 |
| `scripts/build_atlas.py` | 计算取色结果并生成浏览器数据与来源文档 |
| `data/atlas.json`、`data/atlas.js` | 生成结果；JS 版本支持直接打开本地页面 |
| `index.html`、`styles.css`、`app.js` | 页面与交互 |

新增例子时，先选取能核实来源的画面，保留原文件并记录哈希，填写季节依据与三个取样区域，
再运行生成脚本、检查取样框和原图显示。不要手改 `atlas.js` 或 `atlas.json`。
未来颜色章节可以复用影片来源与取样结构；目录已有 `collection` 和逐片 `color` 字段，
届时应同步设置该章节的参考色、筛选与说明，不虚构尚未整理的内容。
